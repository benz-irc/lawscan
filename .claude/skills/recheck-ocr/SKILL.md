# ตรวจ OCR ก่อนจ่ายเงินสแกน

ทุกครั้งที่ OCR คลังใหม่เสร็จ ให้เดินตามนี้ก่อนจะรันคำถาม เพราะข้อความที่ผิด
ทำให้เงินที่จ่ายไปได้คำตอบผิดตาม และความผิดของ OCR ภาษาไทยส่วนใหญ่
**หน้าตาถูกต้อง** — `๒๗` ที่กลายเป็น `๒๓` ไม่มีอะไรบอกว่าผิด

รันสคริปต์ในโฟลเดอร์นี้ตามลำดับ แล้วอ่านผล อย่าเชื่อว่า "ผ่าน" จนกว่าจะเห็นตัวเลข

## 1. คลังครบไหม

```bash
python .claude/skills/recheck-ocr/check.py corpus <โฟลเดอร์ข้อความ> <โฟลเดอร์ pdf>
```

ต้องได้จำนวนไฟล์เท่าจำนวน PDF จำนวนหน้าเท่าผลรวมหน้าของ PDF และไม่มีไฟล์ที่
สั้นผิดปกติ ถ้าจำนวนหน้าไม่ตรง แปลว่ามีหน้าที่อ่านไม่ออกและถูกข้ามไปเงียบ ๆ

## 2. ตัวเลขถูกไหม — วัดกับเฉลยที่เชื่อได้

เอกสารบางฉบับมีชั้นข้อความใน PDF ที่อ่านออกตรง ๆ นั่นคือเฉลยแท้ ไม่ต้องเดา

```bash
python .claude/skills/recheck-ocr/check.py digits <โฟลเดอร์ pdf>
```

รายงานจะบอกว่าอ่านเลขเจอกี่เปอร์เซ็นต์ และ **เขียนรายการทุกจุดที่พลาด**
พร้อมบริบทลงไฟล์ ให้เปิดดูจริง ๆ ไม่ใช่ดูแค่เปอร์เซ็นต์

เกณฑ์ที่เคยวัดได้บนคลังราชกิจจานุเบกษา 2569 — tesseract อ่านเลขไทยผิด
**ทั้งหมด** (0 จาก 153 หน้า) ส่วน macOS Vision ได้ 97%

## 3. ความผิดที่รู้จักแล้ว ตรวจซ้ำทุกครั้ง

```bash
python .claude/skills/recheck-ocr/check.py faults <โฟลเดอร์ข้อความ>
```

| อาการ | ตัวอย่าง | ทางแก้ที่ใช้อยู่ |
|---|---|---|
| ตัวอักษรแทนเลข | `หน้า ด` ที่จริงคือ `หน้า ๑` | `thai_text.repair_numeral_lookalikes` |
| ปีหายหลักแรกหลังทับ | `๓/๕๖๘` | `thai_text.repair_clipped_years` |
| ตัวเศษหน้าทับหาย | `ที่ /๒๕๖๘` | อ่านซ้ำชิ้นนั้นแบบซูม |
| จุดทศนิยมหาย | `๑๐,๐๘๘๘๑` แทน `๑๐,๐๘๘.๘๑` | อ่านซ้ำชิ้นนั้น |
| เลขนำหน้าข้อ | `ด.` แทน `๑.` | อ่านซ้ำชิ้นนั้น |
| วรรณยุกต์หาย | `เลือกตัง` `เรือง` | `thai_text.repair_dropped_marks` |

ถ้าเจออาการใหม่ที่ไม่อยู่ในตาราง **อย่าเขียนกฎเดา** — ให้อ่านซ้ำเฉพาะชิ้นนั้น
ด้วยความละเอียดสูงกว่า เพราะกฎที่เดาจะสร้างตัวเลขที่ไม่เคยมีจริง ซึ่งแย่กว่า
ตัวเลขที่หายไป

## 4. สิ่งที่ห้ามทำ

- **ห้ามเอาเฉลยของผู้ดูแลมาใช้ในทางเดินข้อมูล** ไฟล์เฉลยไม่ได้อยู่ในรีโปแล้ว
  ใช้ได้เฉพาะตอนให้คะแนนผ่าน `lawscan diff --expected` เท่านั้น
- **ห้ามวัดด้วยชั้นข้อความที่ garbled** ตัวถอดรหัสจะคายค่าอย่าง `256๙`
  ที่ไม่ใช่ปีจริง แล้วทำให้ตัวเลขที่รายงานเชื่อไม่ได้ ใช้เฉพาะฉบับที่ชั้นข้อความ
  อ่านออกตรง ๆ
- **ห้ามสรุปว่าดีขึ้นจากตัวอย่างไม่กี่ฉบับ** วัดทั้งชุดที่มีเฉลยเสมอ

## 5. หลังผ่านครบ

รายงานให้ผู้ใช้ทราบว่าเหลือกี่จุด อยู่ฉบับไหน เป็นชนิดไหน และ **กระทบคอลัมน์ไหน
ใน 38 คอลัมน์บ้าง** เลขคดีกับเลขบัญชีไม่มีช่องรองรับ ส่วนเลขมาตราและปีของ
กฎหมายที่อ้างถึงมี — ความสำคัญต่างกันมาก แล้วค่อยถามว่าจะรันคำถามต่อไหม
