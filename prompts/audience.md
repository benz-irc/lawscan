กฎหมายฉบับนี้ผูกพันใคร

## เขียนให้อ่านออกว่า "ใคร" คือใคร

ตอบเป็นชื่อของคนหรือองค์กรที่ต้องทำอะไรเพิ่มขึ้นเพราะฉบับนี้ ความยาวที่เหมาะสม
อยู่ราว 40–80 ตัวอักษร

### ส่วนขยาย เก็บอันไหน ตัดอันไหน

**เก็บ** ถ้ามันเป็นคุณสมบัติที่ติดตัวคนนั้นอยู่แล้ว — หน้าที่ประจำ ตำแหน่ง พื้นที่
เพราะมันคือเส้นแบ่งว่าใครเข้าข่ายและใครไม่เข้า

    ✓ พนักงานเจ้าหน้าที่ที่รับผิดชอบงานตรวจสอบภายใน
    ✓ ผู้ขอรับใบอนุญาตในเขตพื้นที่ที่ประกาศกำหนด

**ตัด** ถ้ามันคือการกระทำตามกฎหมายฉบับนี้ — เขายังเป็นคนกลุ่มเดิมก่อนมีกฎหมายนี้

    ✓ ผู้ประกอบการโรงงาน
    ✗ ผู้ประกอบการโรงงาน`ที่ยื่นคำขอต่ออายุใบอนุญาตตามหลักเกณฑ์ในข้อ ๕`

    ✓ หน่วยงานของรัฐ
    ✗ หน่วยงานของรัฐ`ที่จัดทำรายงานประจำปีส่งภายในเดือนมีนาคม`

**คำถามที่ใช้ตัดสิน** ถ้ายกเลิกกฎหมายฉบับนี้พรุ่งนี้ คนกลุ่มนี้ยังถูกเรียกชื่อแบบนี้อยู่ไหม
ถ้ายัง — เก็บ ถ้าไม่ — ตัด

## ชื่อองค์กรใช้ได้ ชื่อคนไม่ได้

ที่ห้ามคือชื่อบุคคลธรรมดา ไม่ใช่ชื่อนิติบุคคล เมื่อเอกสารทั้งฉบับพูดถึงองค์กรเดียว
ชื่อองค์กรนั้นคือคำตอบที่ตรงที่สุด — การตอบชื่อประเภทกว้างๆ ทั้งที่ประกาศพูดถึง
องค์กรเดียว คือการตอบกว้างกว่าที่เอกสารพูด

    ประกาศ เรื่อง สมาคมกีฬาแห่งจังหวัด ก. สิ้นสภาพ
    ✓ สมาคมกีฬาแห่งจังหวัด ก.
    ✗ สมาคมกีฬา

    คำพิพากษาที่พิมพ์ชื่อ นาย ก. ข. ผู้ถูกกล่าวหา
    ✓ ชื่อชนชั้นที่เขาสังกัด
    ✗ นาย ก. ข.

คำพิพากษาเป็นเรื่องของคนคนหนึ่ง มันพิมพ์ชื่อเขา ชื่อคู่สมรส และสถานะในคดี —
`ผู้คัดค้าน` `ผู้ร้อง` `ผู้ถูกกล่าวหา` ไม่มีอันไหนเป็นกลุ่ม

## นับกลุ่มก่อนเขียน

**นี่คือความผิดพลาดที่พบมากที่สุดของช่องนี้** เอกสารผูกพันคนหลายกลุ่มที่แยกจากกัน
แล้วคำตอบหลอมทุกกลุ่มเป็นวลีเดียว

ไล่ก่อนว่าเอกสารพูดถึงใครบ้าง ถ้าได้มากกว่าหนึ่งกลุ่ม **เขียนแยกคั่นจุลภาค**
อย่าหาคำกลางมาครอบ และอย่าแตกกลุ่มเดียวเป็นหลายกลุ่ม

    ระเบียบที่วางหน้าที่ให้ทั้งกรม สำนักงานจังหวัด และผู้รับใบอนุญาต
    ✓ กรม ก., สำนักงานจังหวัด, ผู้รับใบอนุญาต
    ✗ หน่วยงานที่เกี่ยวข้องกับการอนุญาตทั้งหมด

    ระเบียบภายในที่ไล่ตำแหน่ง ประธาน เลขาธิการ เจ้าหน้าที่ ผู้ช่วยปฏิบัติงาน
    ✓ ไล่ตามที่เอกสารเขียน
    ✗ ยุบเป็น "บุคลากรของสำนักงาน"

### ห้ามใช้ `และ` เชื่อมกลุ่ม — คั่นด้วยจุลภาคเสมอ

ทุกกลุ่มเป็นรายการของตัวเอง เขียนให้ครบทั้งวลี แล้วคั่นด้วย `,`
**ไม่ว่ากลุ่มเหล่านั้นจะดูใกล้กันแค่ไหน**

    ✗ ผู้รับใบอนุญาตประเภท ก. และประเภท ข.
    ✓ ผู้รับใบอนุญาตประเภท ก., ผู้รับใบอนุญาตประเภท ข.

    ✗ ผู้มีหน้าที่แจ้งตามข้อ ๗ และข้อ ๙
    ✓ ผู้มีหน้าที่แจ้งตามข้อ ๗, ผู้มีหน้าที่แจ้งตามข้อ ๙

    ✗ ผู้บริหารและพนักงานของสำนักงาน
    ✓ ผู้บริหารของสำนักงาน, พนักงานของสำนักงาน

    ✗ ประชาชนและผู้ปฏิบัติงานที่หน่วยงาน ก.
    ✓ ประชาชนที่ติดต่อหน่วยงาน ก., ผู้ปฏิบัติงานของหน่วยงาน ก.

**เขียนคำขึ้นต้นหรือคำลงท้ายซ้ำ** อย่าประหยัดคำโดยแลกกับความชัดเจน — คำตอบยาวขึ้น
เล็กน้อย และนั่นคือราคาที่ถูกต้อง เพราะ `และ` ทำให้อ่านได้ว่าเป็นกลุ่มเดียวที่ต้องเข้า
เงื่อนไขทั้งสองข้อ ทั้งที่ความจริงคือสองกลุ่มที่เข้าเงื่อนไขคนละข้อ และคนที่เปิดอ่าน
ต้องบอกได้ทันทีว่าตัวเองอยู่กลุ่มไหน

`และ` ยังใช้ได้ภายในกลุ่มหนึ่ง เมื่อมันเป็นส่วนหนึ่งของชื่อหรือของคำขยาย —
`กระทรวง ก. และ ข.` ที่เป็นชื่อกระทรวงจริง หรือ `ผู้ปฏิบัติงานด้านการเงินและบัญชี`
ที่เป็นหน้าที่เดียว ที่ห้ามคือใช้มันเชื่อม**กลุ่มคน**สองกลุ่มเข้าด้วยกัน

**องค์กรมาก่อน ตำแหน่งตามหลัง**

    สถาบัน ก. ผู้บริหาร คณาจารย์ และผู้เรียน

เมื่อเอกสารระบุตำแหน่งเฉพาะภายในกลุ่มกว้าง เขียนกลุ่มกว้างก่อนแล้วตามด้วยตำแหน่ง:

    ผู้ประกอบวิชาชีพ ก.
    - ผู้ได้รับใบอนุญาตชั้นต้น

ส่วนใหญ่เป็นวลีเดียว รองลงมาเป็นรายการคั่นจุลภาค ที่เป็นสองระดับมีน้อยที่สุด
เลือกตามที่เอกสารเขียน ไม่ใช่ตามความชอบ

## ถามว่าใครได้รับผล ไม่ใช่ใครลงมือ

เอกสารราชการหลายฉบับสั่งให้หน่วยงานทำอะไรบางอย่าง แต่คนที่ถูกผูกพันจริงคือ
คนที่ชีวิตเปลี่ยนเพราะสิ่งนั้น อ่านว่าเอกสาร**ทำอะไร** แล้วจึงตอบว่าใครรับผล

| เอกสารทำอะไร | ผู้รับผลคือ |
|---|---|
| ตั้งหน่วยงานภายในของราชการ | ส่วนราชการในสังกัดหน่วยงานนั้น |
| ย้ายที่ทำการที่ประชาชนไปติดต่อ | ประชาชนและบุคลากรผู้มาติดต่อราชการที่นั่น |
| เปลี่ยนเขตอำนาจของหน่วยงาน | ประชาชนในท้องที่ที่เขตอำนาจเปลี่ยน |
| กำหนดเงื่อนไขประกอบกิจการ | ผู้ประกอบกิจการนั้น หรือผู้ขออนุญาต |
| วางระเบียบภายในองค์กร | ชื่อตำแหน่งที่เอกสารระบุ |

`roles` ใส่ตำแหน่งที่เอกสารระบุชื่อไว้ ถ้ามี — เป็นข้อมูลประกอบ ไม่ใช่คำตอบหลัก
