กฎหมายฉบับนี้ผูกพันใคร

สแกนเนื้อหาเพื่อระบุ **กลุ่มบุคคล นิติบุคคล หรือประเภทธุรกิจ** ที่ได้รับผลกระทบ
มีสิทธิประโยชน์ หรือมีหน้าที่ต้องปฏิบัติตามกฎหมายฉบับนี้

## หนึ่ง — โฟกัสผู้เล่นหลัก

สกัดเฉพาะชื่อของกลุ่มที่กฎหมายฉบับนี้**ตั้งใจออกมาบังคับใช้หรือให้สิทธิประโยชน์ด้วย**

    ‹ผู้ประกอบวงการที่กฎหมายคุม› · ‹ข้าราชการฝ่ายที่ถูกคุม› · บริษัทจำกัด · เกษตรกร

## สอง — ห้ามดึงผู้คุมกฎ

**ห้ามเด็ดขาด** ในการดึงชื่อหน่วยงานรัฐ รัฐมนตรี อธิบดี นายทะเบียน เลขาธิการ
เจ้าหน้าที่รัฐ หรือคณะกรรมการที่มีหน้าที่แค่ **กำกับดูแล รับจดทะเบียน หรือเซ็นอนุมัติ**

    ใน PDF: ให้ผู้ขอรับ‹ชื่อสิทธิ›ยื่นคำขอต่อนายทะเบียน
    ✓ ‹ผู้ประกอบวงการนั้น›            ✗ นายทะเบียน

    ใน PDF: ให้อธิบดีมีอำนาจสั่งเพิกถอนใบอนุญาต‹อาชีพ›
    ✓ ‹อาชีพ›                          ✗ อธิบดี

**ข้อยกเว้นเดียว** คือเอกสารนั้นเป็นระเบียบภายในที่บังคับใช้กับเจ้าหน้าที่รัฐกลุ่มนั้น
โดยตรง — เมื่อนั้นเจ้าหน้าที่กลุ่มนั้นคือกลุ่มเป้าหมาย

## สาม — ยุบรวมคำ แล้วค่อยรวบยอด

**ยุบรวมคำและหน้าที่** กลุ่มที่ขึ้นต้นด้วยคำเดียวกัน หรือทำงานเกี่ยวข้องกัน หรือมี
เลขมาตราที่เอกสารระบุควบคู่กันมา **ห้ามหั่นแยกเป็นหลายรายการ** ให้ยุบเป็นก้อนเดียว

    ✓ เจ้าหน้าที่ที่เกี่ยวข้องกับการรายงานและตรวจสอบ
    ✗ เจ้าหน้าที่ทำรายงาน, เจ้าหน้าที่ตรวจสอบลูกค้า

    ✓ ‹บทบาทที่ตัวบทเรียก›ตามมาตรา ‹ก.› และ ‹ข.›
    ✗ ‹บทบาท›ตามมาตรา ‹ก.›, ‹บทบาท›ตามมาตรา ‹ข.›

**ใช้คำกว้างเมื่อไล่ชื่อย่อยตั้งแต่สามรายการขึ้นไป** ห้ามคัดลอกรายชื่อทั้งหมดมาต่อกันยาว ๆ

    เอกสารระบุ ‹หน่วยย่อย ก.› · ‹หน่วยย่อย ข.› · ‹หน่วยย่อย ค.›   → ‹ชื่อรวบยอดของทั้งกลุ่ม›
    เอกสารระบุ กระทรวง ก. · กระทรวง ข. · กระทรวง ค.   → ส่วนราชการ

## สาม (ต่อ) — แต่ชื่อวงการ กับ บทบาทในกระบวนการ เป็นคนละกลุ่ม

**ห้ามยุบสองอย่างนี้เข้าด้วยกัน** เอกสารที่ตั้งเงื่อนไขของสิทธิอย่างหนึ่ง ผูกพันคนสอง
จำพวกพร้อมกันเสมอ — **คนที่ทำมาหากินในวงการนั้นทั้งวงการ** กับ **คนที่กำลังยื่นขอ
หรือถือสิทธินั้นอยู่** จำพวกแรกกว้างกว่าและรวมคนที่ยังไม่ได้ยื่นด้วย จำพวกหลังแคบกว่า
และมีหน้าที่ตามขั้นตอนโดยตรง

    ✓ ["‹ชื่อวงการธุรกิจ›", "‹บทบาทผู้ยื่นขอหรือผู้ถือสิทธิ›"]
    ✗ ["‹บทบาทผู้ยื่นขอ›"] อย่างเดียว        ✗ ["‹ชื่อวงการ›"] อย่างเดียว

ทั้งสองรายการอยู่ใน array คนละช่อง **ซึ่งจะถูกคั่นด้วยคอมม่าเมื่อเขียนลงตาราง**
ห้ามเอา `และ` หรือเว้นวรรคเชื่อมสองกลุ่มนี้เข้าเป็นสายเดียว

## สี่ — แปลภาษามาตราให้คนธรรมดาเข้าใจ

เอกสารที่ระบุกลุ่มเป้าหมายด้วยการอ้างเลขมาตราหรือกฎหมายอื่น — `ผู้มีหน้าที่…ตามมาตรา…`
`บุคคลตามมาตรา…` — คนทั่วไปอ่านแล้วไม่รู้ว่าใคร **ให้เก็บวลีนั้นไว้ แล้วเติมวงเล็บ
ยกตัวอย่างอาชีพหรือธุรกิจต่อท้าย**

    ✓ ‹กลุ่ม›ตามมาตรา ‹ก.› และ ‹ข.› (เช่น ‹อาชีพ ก.›, ‹อาชีพ ข.›, ‹อาชีพ ค.›)
    ✓ นายจ้างตามมาตรา ‹ก.› (‹นิยามสั้น ๆ ของนายจ้าง›)

## ห้า — เก็บขอบเขตที่กฎหมายจำกัดตัวเองไว้ด้วย

กฎหมายที่บังคับเฉพาะบางพื้นที่ บางขนาด หรือบางเงื่อนไข **ผูกพันเฉพาะคนที่อยู่ใน
ขอบเขตนั้น** ให้เขียนขอบเขตติดไปกับชื่อกลุ่ม ไม่ใช่ตัดทิ้ง

    ✓ ‹กลุ่ม›ในท้องที่‹พื้นที่ที่กฎหมายระบุ›
    ✓ ‹กลุ่ม›ที่‹เงื่อนไขหรือขนาดที่กฎหมายระบุ›

## ทุกรายการต้องเป็นคน ไม่ใช่สถานที่หรือสิ่งของ

ช่องนี้ตอบว่า **ใคร** ต้องทำตาม โรงงาน โรงไฟฟ้า อาคาร ร้าน ไม่ใช่คำตอบ
ให้เขียนเป็นผู้ที่อยู่เบื้องหลังสถานที่นั้น

    ✓ ผู้ประกอบกิจการ‹สถานที่›       ✗ ‹สถานที่›

## รูปคำตอบ

`split` — array หนึ่งกลุ่มเป้าหมายหลักต่อหนึ่งรายการ ภาษากระชับ เข้าใจง่าย

    ["‹ผู้ประกอบวงการที่กฎหมายคุม›"]
    ["ผู้ประกอบกิจการ ก.", "ผู้ให้บริการ ข."]

**หนึ่งรายการยาวไม่เกินราวสิบห้าคำ** ยาวกว่านั้นแปลว่ากำลังลอกนิยามในตัวบทมาทั้งท่อน

**ห้ามสร้างตาราง ห้ามแต่งประโยคอธิบายยาว ๆ ห้ามใส่วงเล็บอธิบายหมวดธุรกิจ**
ยกเว้นวงเล็บแปลภาษามาตราตามข้อสี่เท่านั้น

หากสแกนแล้วไม่พบกลุ่มเป้าหมายที่ชัดเจน ให้เว้นว่าง

**แต่เอกสารที่วางมาตรฐานหรือเงื่อนไขทางเทคนิคย่อมมีคนที่ต้องทำตาม** — ผู้ใช้บริการ
ผู้รับเหมาติดตั้ง ผู้ประกอบวิชาชีพที่เกี่ยวข้อง และประชาชนในเขตที่มาตรฐานนั้นใช้บังคับ
อย่าเว้นว่างเพียงเพราะเอกสารไม่ได้เอ่ยชื่อกลุ่มไว้ตรง ๆ ในประโยคบังคับ
