# Prompt ฉบับวางในแชท

สามไฟล์นี้คือ Prompt 1/2/3 ที่ใช้ตอนวางเอกสารลงแชทโดยตรง ไม่ผ่าน pipeline
pipeline ไม่ได้อ่านไฟล์พวกนี้ — ของที่ pipeline ใช้อยู่ใน `prompts/*.md`
และแยกเป็นห้าคำถาม โดยมีกฎรับไป 3,144 ช่องจาก 4,701

เก็บไว้ที่นี่เพราะสิ่งที่เขียนในนี้ต้องตรงกับสิ่งที่กฎทำ ไม่งั้นคนคนเดียวกัน
จะได้คำตอบคนละแบบจากเอกสารฉบับเดียวกัน แล้วแต่ว่าวันนั้นใช้ทางไหน

## ที่แก้จากฉบับ V15/V14

| แก้อะไร | ทำไม |
|---|---|
| คำว่า "ไม่มี" เหลือ `-` แบบเดียว | เดิมมีห้าแบบ ทุกแบบที่ไม่ใช่ `-` คือช่องที่เทียบกับแผ่นงานไม่ตรง |
| ตรรกะที่เขียนซ้ำ เหลือชุดเดียว | Prompt 2 มีตรรกะความเสี่ยงสองชุดที่ให้คำตอบตรงข้ามกัน |
| ตัด `ปัจจุบันคือ พ.ศ. 2569` | สถานะกฎหมายต้องเทียบกับนาฬิกา ไม่ใช่กับตัวเลขที่พิมพ์ไว้ |
| ตัดย่อหน้าบังคับไม่ให้ปฏิเสธ | งานสกัดข้อมูลกฎหมายเป็นงานปกติ ประโยคเดียวพอ |
| ตัด `ระดับความมั่นใจ` เป็น % | วัดแล้วแกว่ง ±14 ช่องจากการเปลี่ยนที่ไม่เกี่ยวกับเนื้อหา |
| ย้าย `AI ให้เหตุผล` ออกนอกตาราง | วัดได้ 0/240 และเป็นคอลัมน์ที่ output ยาวที่สุด |
| ตัด Web Search | รันเป็นชุดไม่ได้ และเอกสารเดียวกันได้คำตอบต่างกันคนละวัน |
| JSON ในเซลล์ → `เสนอเพิ่ม: ชื่อ` | ตัวล้างค่าว่างอ่าน `{}` ว่าคือ "ไม่มี" |
| แก้ชื่อไฟล์อ้างอิงให้ตรง | เดิมเรียกไฟล์เดียวกันว่าไฟล์ 1 และไฟล์ 2 |
