# ข้อความแจ้งเตือน (Smart Prompt)

เขียน **ข้อความแจ้งเตือนเชิงรุกแบบมีเงื่อนไข พร้อมเช็กลิสต์สิ่งที่ต้องทำ** ให้กับ
**ทุกรหัส V8** ที่วิเคราะห์ได้จากเอกสารฉบับนี้ — หนึ่งรหัสหนึ่งข้อความ

รหัสที่ต้องเขียนให้ คือรหัสในช่อง `กฎหมายเฉพาะธุรกิจ` และ `กฎหมายสนับสนุน`
ที่ส่งมาให้พร้อมเอกสารนี้ ห้ามคิดรหัสขึ้นเอง และห้ามข้ามรหัสใด

## รูปข้อความ — สามส่วน เรียงตามนี้เสมอ

**ส่วนที่ 1 — แจ้งเตือนเงื่อนไข** หนึ่งย่อหน้า

    [‹รหัส V8›]: ระบบพบว่าคุณติดตามหมวด ‹ชื่อหมวดธุรกิจ› ตาม ‹ชื่อกฎหมายฉบับนี้›
    หากคุณมีกิจกรรม ‹เงื่อนไขที่ดึงจากสาระของกฎหมาย› คุณมีความจำเป็นต้อง
    ดำเนินการตามกฎหมาย เพื่อ ‹ผลลัพธ์ที่ได้ หรือความเสี่ยงที่ป้องกันได้›

**ในวงเล็บเหลี่ยมหน้าสุด ต้องเป็นรหัส ไม่ใช่ชื่อหมวด** รหัสคือสิ่งที่ระบบใช้จับคู่
กับผู้ติดตาม ส่วนชื่อหมวดไปอยู่หลังคำว่า `ติดตามหมวด`

    ✓ [‹รหัส›]: ระบบพบว่าคุณติดตามหมวด ‹ชื่อหมวด› ตาม…
    ✗ [‹ชื่อหมวด›]: ระบบพบว่าคุณติดตามหมวด…      ← ไม่มีรหัสให้ระบบจับคู่

รหัสที่ได้รับยกเว้น ให้คงป้ายไว้ด้วย — `[‹รหัส›[Exempted]]`

**ส่วนที่ 2 — เช็กลิสต์ที่ลงมือได้จริง**

    ✅ สิ่งที่คุณต้องทำเบื้องต้น (Actionable Checklist):
    [ ] ‹ชื่อขั้นตอน›: ‹อธิบายสั้น ๆ ว่าต้องทำอะไร›
    [ ] ‹ชื่อขั้นตอน›: ‹อธิบายสั้น ๆ ว่าต้องทำอะไร›

**สูงสุดห้าข้อ** และต้องเป็นข้อที่สำคัญและเร่งด่วนที่สุดก่อน

**ส่วนที่ 3 — หมายเหตุท้าย ใส่เมื่อเข้าเงื่อนไขเท่านั้น**

ถ้ากฎหมายฉบับนี้ซับซ้อน หรือมีขั้นตอนที่ต้องระวังจริง ๆ **เกินห้าข้อ** ให้ปิดท้ายด้วย

    📌 หมายเหตุ: เรื่องนี้มีรายละเอียดข้อปฏิบัติที่ต้องระมัดระวังเพิ่มเติม
    สามารถสั่งซื้อเช็คลิสต์แบบละเอียดได้ที่ ‹ชื่อแพลตฟอร์ม›

ไม่เกินห้าข้อ ไม่ต้องใส่ส่วนนี้

## เงื่อนไขต้องมาจากกฎหมายฉบับนั้น ไม่ใช่คำกลาง ๆ

**ส่วนเงื่อนไข** ให้ดึงสาระสำคัญของกฎหมายมาทำเป็นประโยคเงื่อนไขที่ผู้อ่านตอบตัวเอง
ได้ทันทีว่าเข้าข่ายหรือไม่

    กฎหมายว่าด้วยวิศวกรคุมงานภาครัฐ  →  หากคุณรับงานภาครัฐ
    กฎหมายว่าด้วย‹กิจกรรมที่ควบคุม›   →  หากคุณมี‹กิจกรรมนั้น›

**ห้ามเขียนเงื่อนไขกว้างจนใช้กับกฎหมายฉบับไหนก็ได้** — `หากคุณประกอบธุรกิจ`
ไม่ใช่เงื่อนไข เพราะไม่มีใครตอบว่าไม่ใช่

**ส่วนเช็กลิสต์** ต้องเป็นขั้นตอนที่จับต้องได้ ลงมือทำได้ตามลำดับ ไม่ใช่หลักการ

    ✓ ‹กริยา›‹สิ่งที่ต้องทำ›: ‹รายละเอียดที่พอจะเริ่มทำได้›
    ✗ ปฏิบัติตามกฎหมายอย่างเคร่งครัด
    ✗ ศึกษารายละเอียดเพิ่มเติม

## ภาษา

เขียนให้คนทำงานอ่านรู้เรื่องทันที ตรงไปตรงมา ชวนให้ลงมือ และทำให้เห็นว่าถ้าไม่จัดการ
จะเสี่ยงอะไร **ห้ามใช้ภาษากฎหมายดิบ ๆ** และ **ห้ามอ้างเลขมาตราในส่วนที่ 1 และ 2**

## รูปคำตอบ

ตอบเป็น JSON ที่ **ชื่อคีย์คือรหัส V8** และค่าคือข้อความของรหัสนั้น
คีย์มีมาให้ครบแล้วทุกรหัส — เขียนให้ครบทุกคี่ย์ ห้ามเว้นว่าง

    { "‹รหัส›": "[‹รหัส›]: ระบบพบว่าคุณติดตามหมวด … <br>✅ สิ่งที่คุณต้องทำ…" }

ในตัวข้อความยังต้องขึ้นต้นด้วย `[‹รหัส›]:` เหมือนเดิม เพราะข้อความถูกนำไปต่อกัน
**ห้ามมีคำเกริ่นนำ ห้ามมีคำลงท้าย** และภายในข้อความเดียวกันให้แยกบรรทัดด้วย `<br>`
